| CapCut | 우리 도구 |
| --- | --- |

| 편집 화면: 위 막대(뒤로·제목·내보내기), 가운데 미리보기, 아래 도구 막대(아이콘+글, 옆으로 밀기) | 프로젝트 화면: 위 막대(뒤로·이름·**내보내기**), 가운데 캡처 캔버스, 아래 도구 막대(캡처 추가·번호·박스·화살표·메모·움직임·단계·AI) |
| 도구를 누르면 아래에서 올라오는 시트 | 도구 옵션은 바텀시트 하나로 통일 |

| 아래 탭: 편집·템플릿·내 정보 | 아래 탭: **홈 · 용어 사전 · 설정** |

## 프로젝트 단계 (기본 7단계, 항목은 데이터 파일)
| 단계 | 목표 | 체크 항목 예 |
| --- | --- | --- |
| 1. 아이디어 정리 | 무엇을 누구를 위해 | 한 문장 설명, 쓰는 사람, 꼭 필요한 기능 3개 |
| 2. 화면 목록 | 필요한 화면과 이동 순서 | 화면 이름 목록, 첫 화면 정하기 |
| 3. 참고 화면 모으기 | 비슷한 앱 캡처 | 참고 캡처 3장, 용어 사전으로 부품 이름 찾기 |
| 4. 표시하기 | 캡처에 번호·박스·움직임 | 화면마다 번호와 한 줄 설명 |
| 5. AI에게 지시하기 | 내보낸 그림 + 지시문 전달 | 한 번에 화면 하나씩, 결과 받기 |
| 6. 확인·고치기 | 결과 캡처 → 다시 표시 | 폰 폭에서 확인, 고칠 것 표시해 다시 요청 |
| 7. 출시 준비 | 남에게 보여 줄 준비 | 개인정보 확인, 아이콘·이름, 친구 1명 써 보기 |
- 사용자는 항목을 체크·해제하고, 자기 항목을 더하고 지울 수 있다. 단계는 순서대로 열려 있되 건너뛰기도 된다(강제 아님).

## LLM 연결 원칙
- **기본은 꺼짐.** 꺼져 있으면 사진·글이 기기 밖으로 나가지 않는다.
- 켜려면 설정에서 회사(Claude / ChatGPT)·API 키·모델을 넣는다. 키는 그 기기 브라우저 저장소에만, 화면에 "이 기기에만 저장돼요" 안내와 지우기 버튼.
- **보낼 때마다 확인 창**: 무엇(이미지 몇 장·글)을 어느 회사로 보내는지 보여 주고 사용자가 눌러야 보낸다.
- 첫 기능: "AI로 지시문 다듬기" — 캡처 + 번호별 지시문을 보내 더 분명한 지시문을 받아 바꿔 넣기(바꾸기 전 비교).
- Claude 기본 모델 `claude-opus-5-5`, ChatGPT는 설정에서 모델 이름 입력. 회사는 공급자(provider) 모듈로 나눠 나중에 더하기 쉽게.
